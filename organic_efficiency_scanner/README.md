# Organic Efficiency Scanner

## Описание
Интерактивный инструмент для анализа эффективности закупки трафика мобильных приложений на Google Play.  
Позволяет оценить Efficiency Index (EI) — показатель того, насколько эффективно приложение превращает платный трафик в органический, а также получить рекомендации по ключевым метрикам (DAU, монетизация, paid, ранг).

## Данные
- Источник: агрегированные CSV по приложениям Google Play (SensorTower, US).  
- Метрики: DAU, Revenue, Rank, Paid traffic, Organic traffic.  
- Дополнительно: синтетические латентные факторы (NMF).

## Модель
- **Таргет (EI):** чувствительность органики к paid (∆logO / ∆logP), нормированная на локальную медиану конкурентов.  
- **Фичи:** логарифмы метрик, sRank, recency, латентные факторы.  
- **Модель:** CatBoost Quantile Regressor (p25, p50, p75).  
- **Артефакты:** `joblib` модели и мета-информация.

## UI
- Реализован в Gradio.  
- Ввод: DAU, Paid, Organic, Rank, Target organic.  
- Вывод:  
  - Прогноз органики по модели.  
  - Приоритетные драйверы (SHAP).  
  - Рекомендации (пошаговые и итоговые).  

# Установка зависимостей
pip install -r requirements.txt

## Training pipeline

**Файл:** `train_pipeline.ipynb`  
Запускает полный цикл обучения Efficiency Index (EI): загрузка данных с Google Drive, очистка и фичи (логарифмы, sRank, recency), расчёт таргета (ΔlogO/ΔlogP) и локальной нормализации по конкурентам, извлечение латентных факторов (NMF), обучение CatBoost Quantile моделей (p25/p50/p75), сохранение артефактов.

**Запуск:**
pip install -r requirements.txt
python train_pipeline.ipynb

## Output artifacts
После обучения (`python train_pipeline.ipynb`) создаётся папка `ei_artifacts/` с моделями и метаданными.

# запуск UI
python calculator_ui.ipynb

## Использованиие

- Ввод текущих средних дневных метрик приложения (paid, dau, organic, rank), категории и желаемого объема органического трафика (target organic). 
- Запуск для получения рекомендаций по первой итерации изменений (основан на SHAP). 
- Можно также увидеть суммарные изменения за все итерации и их количество с помощью "сводной рекомендации".
